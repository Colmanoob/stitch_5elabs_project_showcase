# Client Guide: How to Manage your Website Files

Welcome to your website's built-in File Manager! We have designed this to be as simple as possible. When you add a file here, it will automatically appear as a shiny new download button on your public **Downloads** page.

## Step 1: Log In
1. Open your web browser and go to your website address followed by `/admin.php`
   > Example: `www.yourwebsite.com/admin.php`
2. You will see a login screen. Enter your password.
   *(Please ask your developer for your initial password)*

## Step 2: Upload a File
1. Once logged in, click inside the dotted box that says **"Click to select file"**.
2. Find the file on your computer (for example, a `.zip` archive or a `.pdf`) and select it.
3. **Important Checkbox:** If you are trying to *replace* an old file with a newer version that has the exact same name, make sure to check the box that says "Replace existing file...". If you leave it unchecked and the file already exists, the server will automatically keep the old file and save the new one by adding a timestamp to the end of the newly uploaded file's name.
4. Click the blue **"Upload File"** button.

## Step 3: Manage Existing Files
Below the upload area, you will see a list of all files currently on your website.
- **Rename:** Click the "Rename" button to change a file's name. Please make sure to keep the file extension intact (e.g., if you rename `Report.pdf`, rename it to `New-Report.pdf`).
- **Delete:** Click the "Delete" button to permanently delete the file from the server. It will instantly disappear from the public downloads page.

## Step 4: Check the Results
1. Click the link at the bottom that says **"View Downloads Page"**.
2. You will instantly see your newly uploaded (or renamed) files perfectly formatted with the file size and a download button. 

## Best Practices
- **File Sizes:** The uploader allows a maximum of 500MB per file. If you have files larger than that, please consider breaking them up into parts.
- **Allowed Types:** We currently allow all general files including archives (`.zip`, `.rar`), documents (`.pdf`, `.docx`, `.xlsx`), images, and video files. 
- **Naming Files:** Give your files clear names before uploading them (e.g., `Ethical_Land_Resources.zip`), as this is what visitors will see.
